# 🛒 E-Commerce Admin Dashboard

A responsive e-commerce admin dashboard built using HTML5 and CSS3.

## 🚀 Live Demo

https://bhoiswati1106-sys.github.io/ecommerce-admin-dashboard/

## ✨ Features

- Responsive admin dashboard layout
- Sidebar navigation
- Revenue, orders, products and customer statistics
- Sales overview
- Top products performance
- Recent orders
- Responsive CSS Grid and Flexbox
- CSS design tokens
- Modern cards, shadows and hover effects
- Mobile-first responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Custom Properties
- CSS Grid
- Flexbox
- Media Queries

## 📱 Responsive Testing

The dashboard was tested at:

- 320px — Mobile
- 768px — Tablet
- 1024px — Laptop / Tablet
- 1440px — Desktop

The layout was tested without horizontal scrolling.
