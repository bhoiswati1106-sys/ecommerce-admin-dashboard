# 🛒 E-commerce Admin Dashboard

A responsive admin dashboard for an online store that works on desktop, tablet and mobile screens. Built as part of my Full Stack Web Development internship at RabTech Academy.

🔗 **Live Demo:** https://bhoiswati1106-sys.github.io/ecommerce-admin-dashboard/

![Dashboard Screenshot](docs/screenshot.png)

## ✨ Features

- Sidebar navigation (Orders, Products, Customers, Settings)
- Summary cards for total revenue, orders, products and customers
- Sales overview chart with a "Last 7 days" selector
- Top products list with units sold and revenue
- Recent orders table with colour-coded status labels (Delivered, Pending, Cancelled)
- Fully responsive layout for desktop, tablet and mobile

## 🛠️ Built With

- HTML5
- CSS3 (CSS Grid, Flexbox, CSS variables / design tokens)
- Responsive Web Design (mobile-first breakpoints)

## 🚀 How to Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/bhoiswati1106-sys/ecommerce-admin-dashboard.git
   ```
2. Open the project folder
   ```bash
   cd ecommerce-admin-dashboard
   ```
3. Open `index.html` in your browser. No installation is needed.
